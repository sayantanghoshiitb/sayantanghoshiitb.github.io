# Wildlife missing-photo design

Reference: [Empty State by Serafim on 21st.dev](https://21st.dev/@serafimcloud/components/empty-state), specifically its icon-led media empty-state pattern.

The pattern is adapted as static HTML and CSS for this existing static website. A camera icon, a softly layered frame and a neutral background communicate a missing photograph without suggesting that a download is loading. Decorative artwork is hidden from assistive technology. The existing text, "Seen · photo not available", remains unchanged. No new React runtime or client dependency is needed.
